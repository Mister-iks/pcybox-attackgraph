# @pcybox/attackgraph-schema

The JSON Schema of the `.attackgraph.json` lab format of [PCYBOX AttackGraph](https://github.com/Mister-iks/pcybox-attackgraph). Use it to validate labs or to get completion in editors.

```ts
import schema from '@pcybox/attackgraph-schema/lab.schema.json' with { type: 'json' };
```

The format is documented in [docs/lab-format.md](https://github.com/Mister-iks/pcybox-attackgraph/blob/main/docs/lab-format.md). Until 1.0, minor versions may change the format.
