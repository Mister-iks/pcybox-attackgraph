# @pcybox/attackgraph-i18n

Messages (ICU MessageFormat, English and French) and lab text formatting shared by the [PCYBOX AttackGraph](https://github.com/Mister-iks/pcybox-attackgraph) web app and command line tool. It turns the engine's message ids into localized sentences.

```ts
import { createLabFormatter, pick } from '@pcybox/attackgraph-i18n';
import en from '@pcybox/attackgraph-i18n/messages/en.json' with { type: 'json' };
```

Translations are welcome: see [CONTRIBUTING.md](https://github.com/Mister-iks/pcybox-attackgraph/blob/main/CONTRIBUTING.md).
